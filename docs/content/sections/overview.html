OmniCore

A Go framework for DDD + CQRS microservices

github.com/ClaudioSchirmer/omnicore Go ≥ 1.21 Fiber v3 · pgx v5 · mongo-driver v2 · kafka-go

Overview

OmniCore is a Go library that provides all the technical and architectural infrastructure for building microservices with Domain-Driven Design and CQRS following the idiomatic Go pattern. Services import the module and automatically gain: typed validation, atomic persistence with outbox, guaranteed auditing, multi-language, structured logging, CQRS pipeline, and a standardized HTTP layer via Fiber.

Philosophy: the framework orchestrates the critical flows (validation, transaction, outbox, audit, translation, HTTP response) and lets the developer focus exclusively on the business rules. Essential functionality cannot be forgotten — the framework guarantees it.

A throughline worth knowing up front: a handler is written once and is invariant across the surface it is attached to. A command handler attaches to HTTP or to Kafka; a query handler attaches to HTTP/JSON, to CSV, or to Excel — the same handler, the surface decides only the I/O shape. Serving a new channel is a new attachment, not new logic. See Handler invariance.
