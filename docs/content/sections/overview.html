OmniCore

A Go framework for DDD + CQRS microservices

github.com/ClaudioSchirmer/omnicore Go ≥ 1.21 Fiber v3 · pgx v5 · mongo-driver v2 · kafka-go · gqlparser v2

Overview

OmniCore is a Go library that provides all the technical and architectural infrastructure for building microservices with Domain-Driven Design and CQRS following the idiomatic Go pattern. Services import the module and automatically gain: typed validation, atomic persistence with outbox, guaranteed auditing, multi-language, structured logging, the CQRS pipeline, and standardized REST and GraphQL surfaces via Fiber — with OpenAPI 3.1 docs and CSV/XLSX tabular export reflected from the same Go types.

Philosophy: the framework orchestrates the critical flows (validation, transaction, outbox, audit, translation, HTTP response) and lets the developer focus exclusively on the business rules. Essential functionality cannot be forgotten — the framework guarantees it.
Battle-tested: the framework ships with 91.6% unit-test coverage of its statements. That confidence is backed by 64,420 lines of tests against 42,863 lines of production code — a 1.50 : 1 test-to-code ratio: there is roughly half again as much test code as there is framework code exercising it.
