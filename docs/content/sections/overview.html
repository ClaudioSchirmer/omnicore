Overview

OmniCore is a Go library that provides all the technical and architectural infrastructure for building microservices with Domain-Driven Design and CQRS following the idiomatic Go pattern. Services import the module and automatically gain: typed validation, atomic persistence with outbox, guaranteed auditing, multi-language, structured logging, the CQRS pipeline, and standardized REST, gRPC, and GraphQL surfaces — with OpenAPI 3.1 docs and CSV/XLSX tabular export reflected from the same Go types.

Philosophy: the framework orchestrates the critical flows (validation, transaction, outbox, audit, translation, HTTP response) and lets the developer focus exclusively on the business rules. Essential functionality cannot be forgotten — the framework guarantees it.

New here? The capability map lays out everything the framework does, grouped by what you are building; Architecture covers the 4-layer model and dependency rules; and Handler invariance explains the guarantee that one handler serves every surface.
