Architecture

The 4 layers

web/HTTP transport (Fiber v3), JWT auth middleware · Semantic → HTTP status · canonical response envelope · CSV/XLSX export
openapi/OpenAPI 3.1 + Swagger UI, generated from your Go types
graphql/GraphQL endpoint — own surface, reflected from the same DTOs, never in Swagger
queryschema/shared read-side DTO reflection (REST + OpenAPI + GraphQL) — one traversal, three projections
application/
configuration/AppContext (UUID + Language + Identity)
translation/Translator + 7 language modules (PT-BR / ENG / ES / FR / DE / IT / NL)
notifications/ContextDTO / MessageDTO (carries NotificationKey + Semantic)
pipeline/Handler[TReq,TRes], Result[T], Pipeline, Request / Command / Query
persistence/ScopedRepository[T] = Reader[T] + Scope · TxHandle + AfterBegin / BeforeCommit hooks
queries/QueryHandler + ViewReader · keyset pagination, sparse ?fields=, sort, filters
handlers/Auto Command + Query Handlers — generic CRUD with zero handler code
domain/Pure business rules — ZERO IO (stdlib + google/uuid only)
ValidEntity (Insertable / Updatable / Archivable / Deletable / Unarchivable / Batch)
AggregateRoot + AggregateRootProvider · Rules DSL · Old-state snapshot
Typed Notification system (translation key = struct name)
infra/Relational backend — PostgreSQL or MySQL (+ transactional outbox + audit), Mongo views, Kafka SyncEngine
aggregate_persister (automatic dispatch) · composer · rebuild (Mongo schema evolution)
cache/ · httpclient/ · integration/ (events) · db/criteria/ (entity search engine)
migration/ · upstream_subscriber (cross-service) · audit / events

Dependency rules

Layer May import NEVER imports
domain stdlib + google/uuid only everything else
application/* domain, other application/* infra, web
infra domain, application/persistence (infra implements the ScopedRepository write binding + TxHandle/hook interfaces; audit emission is owned by infra itself) web
web domain, application/* infra directly
How errors traverse layers without cross-imports: the domain.NotificationCarrier interface (error + NotificationContexts() []*NotificationContext) is implemented by DomainError, ApplicationError, and InfrastructureError. The Pipeline uses errors.As(err, &carrier) and handles any of them uniformly — without needing to import specific packages.
