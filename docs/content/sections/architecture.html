Architecture

The 4 layers

┌──────────────────────────────────────────────────────────────────┐
│  web/             HTTP transport, response shape, middleware       │
│                   semanticToStatus (Semantic → 404/409/403/422/…)  │
│  application/                                                       │
│    configuration/  AppContext, Language                             │
│    translation/    Translator, PT_BR/ENG/ES/FR/DE/IT/NL modules     │
│    notifications/  ContextDTO/MessageDTO (with NotificationKey)     │
│    pipeline/       Pipeline, Result[T], Request/Command/Query       │
│    persistence/    ScopedRepository[T] = Reader[T] + Scope          │
│                    (binds ctx + WriteOption hooks) → domain.Writer   │
│                    TxHandle + AfterBegin/BeforeCommit hook types     │
│    queries/        FindByParamsQuery + FindByIDQuery + ViewReader  │
│  domain/          Pure business rules (zero IO)                    │
│                   AggregateChildren, AggregateRootProvider          │
│  infra/           Postgres, Mongo, Kafka, audit/events/log         │
│                   aggregate_persister (automatic dispatch)          │
└──────────────────────────────────────────────────────────────────┘

Dependency rules

Layer May import NEVER imports
domain stdlib + google/uuid only everything else
application/* domain, other application/* infra, web
infra domain (the persistence layer implements the Repository port; audit emission is owned by infra itself) web
web domain, application/* infra directly
How errors traverse layers without cross-imports: the domain.NotificationCarrier interface (error + NotificationContexts() []*NotificationContext) is implemented by DomainError, ApplicationError, and InfrastructureError. The Pipeline uses errors.As(err, &carrier) and handles any of them uniformly — without needing to import specific packages.
