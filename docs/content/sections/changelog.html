Changelog

Notable changes to the framework, newest first — a consumer-facing digest of the public surface. The exhaustive, per-symbol list (Keep a Changelog format, SemVer) lives in CHANGELOG.md at the repository root. While in 0.x.y the public API may change between minor versions; breaking changes are called out under Changed. When you ship a feature, add a new release block at the top and bump the v… badge in index.html.

Unreleased—
  • Added — TableSchema, the single mandatory explicit Go-field↔column map, supersedes the convention/inference model and the RepoConfig map. Built with NewTableSchema[T](table) (validates each field against T at construction — a typo is a boot panic) or NewExternalSchema(table) (type-less, for external FromSchema sources); chainable PK / FK / Field / SoftDelete / CreatedAt / UpdatedAt / Child. No name inference — every persisted field is declared; an undeclared exported field is runtime-only by construction. See TableSchema (PG + views).
  • Added — BaseAggregateRepository.WithSchema(*TableSchema) threads the one schema into the write binding and the read loader (write SQL + criteria + auto-scan); children come from the schema's Child(...) declarations.
  • Added — the same schema drives the Mongo read side: ViewDefinition.Schema(ts) (root) and fwinfra.FromSchema(ts) (embed). The composer writes physical columns; the reader translates each leaf back to its Go field name, so the typed Response speaks Go names with only json: tags.
  • Added — fwinfra.FromSchema(*TableSchema), the single embed source constructor: table/collection, store kind (type-anchored NewTableSchema[T] → local Postgres; type-less NewExternalSchema → external/Mongo), and the EmbedMany join FK are all derived from the schema. A local embed derives its Go segment from the schema's Go type (pluralized for EmbedMany); .As(...) is an optional override there and required on an external embed; .On(key) is one-to-one-Embed-only. Plus infra.ValidateViewSchemas (fatal boot enforcement that every view root + embed declares a schema, and every external embed declares .As) and the now-exported domain.PluralizeWord. See TableSchema (PG + views).
  • Removed — RepoConfig / SourceMap / ManagedColumn, WithChild / WithChildAutoScan / WithConfig, ViewOf[*T](), the view:"<docKey>" Response tag, the transient:"-" tag entirely (no longer read by any layer — a field is persisted iff declared in the TableSchema, and gets a label iff it carries a label: tag), and the name-inference helpers (PluralizeSnake / PascalToSnake for persistence names). Manual scanners (WithRootScanner / WithChildScanner) remain.
  • Removed — the From(string) / FromMongo(string) string constructors and the Source.Schema(ts) method (replaced by FromSchema(ts)), plus the view.embed.schemaless boot advisory and its identity pass-through fallback (Source.SchemaDef() and the schema-less detection helper go with them). Schema is now mandatory on every view, not optional — there is no slog.Warn and no pass-through mode.
  • Changed — breaking: persistence names are no longer derived from Go identifiers; every Repository and view must declare a TableSchema and call WithSchema. Every view must declare a schema on the root AND on every embed; the embed's table, join FK, and store kind come from the schema (FromSchema); .On is now one-to-one-Embed-only and external embeds must declare .As. The read-side wire↔doc translation is a two-hop pivot — the web layer maps a wire path to the Go field path (via json: tags), and the reader translates the Go path → physical column (via the view's TableSchema). The aggregate-child notification segment is now camelCase (OrderLine → orderLines).
v0.11.0June 19, 2026
  • Added — PG schema mapping: RepoConfig is now the single, complete per-Repository schema map (root flat fields + a Children map[string]SourceMap tree). It controls the table, the primary-key column, per-field columns (root and per child), and the three framework-managed columns (SoftDelete / UpdatedAt / CreatedAt) via ManagedColumn{Disabled, Column}. See TableSchema (PG + views).
  • Added — BaseAggregateRepository.WithSchema(cfg) threads the map into both the write binding and the read loader from one declaration, and runs boot checks (column bijection, mapped-field-is-persistable, Modes() ⟺ SoftDelete).
  • Added — the framework now actively stamps created_at = NOW() (and updated_at = NOW()) on INSERT instead of relying on a DB DEFAULT it does not own.
  • Fixed — the read/scan-back path now honors column renames. Previously a field mapped to a non-convention column (e.g. Email → mail) was written and filtered correctly but scanned back by the convention column, so the row could not be read through FindByID/FindOne. The SELECT list and the scanner now share a per-Repository mappedColumn → field resolver.
  • Changed — audit now speaks the faithful domain vocabulary: snapshot keys and changes[].field carry the raw Go field name (Email, ZipCode) instead of the snake_case column. Audit is map-blind, so a column rename never disturbs the timeline. Consumers keying audit on the old snake_case field names must update.
  • Changed — RepoConfig.FieldOverrides / ChildTableOverrides / ChildFKOverrides are replaced by RepoConfig.Fields and the per-child SourceMap (Table / FK / Fields) under Children.
v0.10.0June 17, 2026
  • Changed — moved the criteria query DSL from omnicore/criteria to omnicore/infra/criteria. The package name is unchanged; only the import path moves. The DSL is consumed solely by the infra layer, so it no longer sits at the root.
v0.9.0June 17, 2026
  • Added — entity search engine: the backend-neutral criteria query DSL plus AggregateLoader[T].FindOne / FindAll(ctx, *criteria.Query) to load live aggregates (root + children, batched — no N+1) by any criterion, not just by id.
  • Added — pure domain repository ports domain.Reader[T], domain.Writer, domain.Repository[T] (ctx-less, hook-less).
  • Changed — the write path is now Scope-bound: repo.Scope(ctx, opts...).Insert(valid) binds the request ctx + in-TX lifecycle hooks and returns a pure domain.Writer. Reads stay direct on the handle via persistence.ScopedRepository[T].
  • Removed — domain.Context, persistence.Writer[T], and AggregateLoader.Load / LoadIncludingArchived (the last replaced by FindOne(criteria.ByID(id))).
v0.8.0June 16, 2026
  • Added — generic byte-level cache subsystem (omnicore/infra/cache): one cache.Cache port (Get / Set / Delete), in-process LRU+TTL and Redis backends, typed GetJSON / SetJSON helpers, and private + shared instances on Deps driven by a top-level cache: YAML block.
  • Changed — the outbound httpclient response cache now consumes Deps.Cache; the httpClient.defaults.cache block keeps policy knobs only.
  • Removed — httpclient.Cache / WithCacheStore, superseded by cache.Cache / WithCache.
v0.7.0June 16, 2026
  • Added — field labels: a label:"<catalogKey>" struct tag renders a translated human-readable label next to the technical field name on every reactive output (MessageDTO.FieldLabel on the wire, FieldChange.FieldLabelKey rendered at read on audit rows).
  • Added — audit read helpers audit.RenderLabels / RenderLabelsInJSON and reader helpers audit.FindByID / FindByAggregate.
v0.6.0June 16, 2026
  • Added — cross-service integration events (omnicore/infra/integration): the producer surface (Dispatch with WithTx / WithAggregateID / correlation) and the consumer surface (Registry, Receiver, ConsumerPool). Handlers are invariant across HTTP and Kafka transports.
  • Added — IntegrationFeature bootstrap hook, integration: + shutdown: YAML blocks, embedded migration 0002_integration_events, and correlation/causation propagation on AppContext.
v0.5.0June 15, 2026
  • Changed — upgraded Fiber v2 → v3. Breaking across the HTTP layer: handlers take fiber.Ctx (interface, no pointer), body/query binding moves to the unified c.Bind() API, and several config shapes change. Consumer services upgrade in lock-step after the framework tag is cut.
  • Changed — bumped pgx to v5.10.0 (security hardening, no breaking changes).
  • Removed — thin wrappers web.CORS, web.Logger, web.RateLimit (call the Fiber v3 middleware directly). web.Recover() is kept for its slog-integrated stack handler.
v0.4.0June 14, 2026
  • Added — parameterized notifications: tvar:"<name>" struct tags substitute runtime values into translated messages, with per-emit Vars overrides and the new Translator.Render / Interpolate surface.
  • Changed — persistence.TxHandle is now a sealed marker with no public methods; infra.UnwrapPgxTx is the single authorized bridge to the underlying pgx.Tx, making "application is SQL-free" a type-system guarantee.
v0.3.0June 13, 2026
  • Added — initial public release of the rewritten history (skips v0.1.0 / v0.2.0, both frozen on the module proxy from a prior repo). Ships the whole framework: DDD layering with enforced boundaries, sealed ValidEntity types, aggregate-aware persistence with universal symmetric cascade, the Rules DSL, the typed notification system, Result[T] + Pipeline, Auto Command and Query Handlers, OpenAPI 3.1 + Swagger UI, JWT auth with three-layer authorization, dual-destination audit, the httpclient outbound subsystem, cross-service composition, Mongo schema evolution, migrations, declarative YAML config, and bootstrap.Run.
